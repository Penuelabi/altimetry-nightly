3 Access keys, created by the admin

One key per person, issued by the admin.

The admin creates each user, picks a role and an expiry, and the app generates a random access key. The key is shown once for the admin to hand over. GitHub keeps only a salted hash in a private repository, so even someone who reads the repo cannot sign in. Revoking a user is one commit; every phone picks it up at its next sync.

Where secrets live
Private repo abuk-access: users.json with ID, role, scope, expiry and key hash. No plain keys.
GitHub Actions secrets: the service account and DAHITI / Hydroweb keys the nightly workflow already uses.
Admin phone only: the admin's own GitHub token, in secure storage, used to commit new users.
Worker phones: a session token after first sign‑in, plus a 4‑digit PIN for offline unlock.

3bWorker sign‑in · try EW‑014 + abk_anything

2 Data sources & crop monitoring

Pull the climate in; send the field out.

Yes, both work. Your altimetry-nightly workflow already refreshes DAHITI/Hydroweb water levels and Earth Engine climate every night at 00:00 Cairo into the colab_waterlevel Drive folder; the app reads those files directly. When the phone has signal it pulls only changed files, clipped to the 40 ha boundary so they stay small, and the flood model re-runs on the cached set. Crop checks go the other way: saved on the phone, then appended to a Drive sheet the extension team already reads.

What it needs to be real
A public or token‑read GitHub repo (raw CSV/GeoTIFF or release assets), and a shared Drive folder authorised once by the project admin.
A small server job to clip national rasters to the farm. Phones shouldn't download whole Sentinel scenes.
Extension worker IDs issued by the county office; the form checks the EW‑### format.
2aData sources: real Drive + Earth Engine files, filtered to a 10 / 20 / 50 km radius
2bCrop check form: scroll; save empty to see validation

1 Duk County · Abuk Project · Android field app

A farm that runs on the river.

One offline‑first app for the 160 farmers working 40 ha of Balanites, Moringa and native crops in Duk County. Farm operations lead the navigation; the species guide and cooperative market sit beside them. Every phone below is fully clickable. Tap tasks, drag the flood slider, map a plot, log a harvest, toggle online/offline and EN / عربي / DIN in the header.

Assumptions
Three zones: dry ridge 10 ha, slope 8 ha, floodplain basin 22 ha with Balanites on 1 m mounds, 7 m apart.
Mixed farmer model: 112 individual and 48 group plots, run by group leads who tick tasks for members without phones.
GPS works offline; elevation, slope and the flood model refresh from terrain, weather, river gauge and satellite data when a signal returns.
All figures are sample data. Dinka strings await a community translator.
